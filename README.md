# Scroll portfolio study

依据参考录屏和补充截图搭建的四段滚动交互：开场主体缩放与流动穿插、中央缩小画面与横向大字、深色错位图片墙、左右双栏入口。首页已接入用户提供的两张透明人物照片，其他图片和文案保留占位。

## 预览

在本目录执行 `node preview.mjs`，打开终端显示的本地地址。网站也可以直接打开 `dist/index.html`。

## 替换内容

编辑 `dist/content.js`。将图片放进 `dist/assets/`，填写对应路径即可。`heroImage` 推荐透明背景的半身 PNG/WebP；左右入口推荐透明背景侧面图片。没有填写图片时，页面会显示代码绘制的中性占位图。

- `name`：左上角两行标识。
- `heroImage` / `heroHelmetImage`：首页人物与头盔形象，两张透明 PNG 需要使用相同画布和人物位置。
- `message.lines`：缩小画面后方的两行超大占位文字。
- `gallery`：八张图片及对应的小标题。
- `entries`：两个入口的两行标题、描述和图片。
- `pages.work` / `pages.life`：专业作品与日常生活内页。`heroImage` 替换大幅主视觉；`statementImage` 替换中央缩放图片；`statement` 是三行介绍标题；`projects` 填写项目名称、类别、主图和细节图。

滚轮、触控板、触屏和键盘滚动共享同一条连续时间线。鼠标移动驱动主体转动、图层视差、光照方向和图片倾斜。缩小画面上的荧光笔划按滚动进度描绘；进入白色段落时，椭圆遮罩逐渐展开，深色画面退远，双栏内容进入。所有转场均可随反向滚动还原。右侧章节导航和菜单可以直接定位。点击任意画廊图片框，会通过约 0.85 秒的连续转场前往“专业作品 / 日常生活”双栏入口，完成后键盘焦点落在“专业作品”；滚轮可随时中断跳转。双栏入口分别进入专业作品和日常生活内页。页面包含小屏布局、键盘焦点和减少动画偏好支持。

滚动行程为原版的三分之二。滚轮、章节跳转由同一个动画循环控制，页面位置与画面同步；触屏和键盘保持原生滚动。普通鼠标滚轮使用 1.35 倍推进，触控板保留原始增量；反向输入会立即取消上一方向的余量。隐藏场景暂停逐帧更新，转场环使用缩放替代宽高变化。

## 内页与项目浏览

首页双栏的两个按钮分别进入 `#work` 和 `#life`。进入、切换和返回都经过蓝色全屏标识遮罩转场。内页使用黑底与道奇蓝强调色，依次展示大幅主视觉、滚动缩放的中央图文、错位图片和横向浏览区。

专业作品页从创作介绍直接进入“个人项目”，不再展示中间的错位“专业项目”图片区域。个人项目分为“项目01”“项目02”“项目03”“other work”四项，每项只有一个封面（`image`）和标题。`showGallery: false` 控制移除错位图片区域，`projectLayout: "covers"` 使用单封面排版；章节和项目进度会按实际内容更新。日常生活页保留原有结构。

“个人项目”区使用固定视窗：向下滚动使封面向左横移，反向滚动则退回；到达第四项后，页面继续向下进入页尾。章节按钮、项目进度按钮、键盘左右键都可以定位。手机上也可通过上下滑动浏览横向项目。点击项目图片可打开占位预览，页尾可以切换到另一个内页或返回入口。浏览器后退和直接内页链接均受支持。

内页结构和动画在 `dist/pages.js`、样式在 `dist/pages.css`。录屏仅作为开发参考，不会随网站上传。

## 首页流动穿插

`dist/fluid-hero.js` 用同一坐标下的两张透明照片生成弯曲、两端收尖的流体透镜。轮廓有不对称的弧面、回弯与折射；头盔表面叠加很淡的三角线框。独立的全屏半透明流体层延伸到人物之外的留白区域，包含漂浮薄片和小液滴。鼠标静止时自动旋转、上下穿行；移动鼠标时，主体和外围薄片平滑跟随，移动速度增加边缘折射。停止移动后逐渐回到自动流动。两张图片的肩部和头发保持对齐，图片原文件不经过修改。

随滚动缩小，流体、头盔线框与外围薄片逐渐消退，同时人物画面连续去色为灰色。完全缩小后只显示静态灰色人物图，外面的道奇蓝背景、文字和笔划保持蓝色。反向滚动可恢复彩色人物和流体效果。

人物以底部为缩放锚点，画框下沿与人物底部联动。整个缩小行程保持少量裁切余量，避免透明 PNG 的水平底边提前露在画框内；鼠标视差也遵循相同的底边约束。

首页开场人物与头盔整体缩小约 10%，缩小过程的中间比例同步调整，底部对齐约束继续生效。主菜单只有 HOME、专业作品、日常生活三项；HOME 从任意页面直接回到首页开场并关闭菜单。

支持 WebGL 加速；无法使用时退回 Canvas 切片，再无法渲染时显示原始人物图。渲染分辨率有上限，离开首页、打开菜单、进入内页或隐藏标签页时暂停。系统开启“减少动态效果”时使用静态人物图。

原目录中的 `index.html` 和 `styles.css` 保持原样。开发参考素材位于 `reference/`，不随网站发布。

## 当前配色

深色面板采用参考图片取色的深蓝渐变：`#195392 → #053675 → #002569`。强调色为道奇蓝 `#1E90FF`；深色背景上的小号强调文字使用浅蓝 `#67B5FF`。配色集中在 `dist/styles.css` 的 `--deep-blue`、`--scene-fill`、`--accent` 和 `--accent-soft` 中。
