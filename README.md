# Scroll portfolio study

依据参考录屏和补充截图搭建的四段滚动交互：开场主体缩放与拆分、中央缩小画面与横向大字、深色错位图片墙、左右双栏入口。正式图片和文案均为占位。

## 预览

在本目录执行 `node preview.mjs`，打开终端显示的本地地址。网站也可以直接打开 `dist/index.html`。

## 替换内容

编辑 `dist/content.js`。将图片放进 `dist/assets/`，填写对应路径即可。`heroImage` 推荐透明背景的半身 PNG/WebP；左右入口推荐透明背景侧面图片。没有填写图片时，页面会显示代码绘制的中性占位图。

- `name`：左上角两行标识。
- `message.lines`：缩小画面后方的两行超大占位文字。
- `gallery`：八张图片及对应的小标题。
- `entries`：两个入口的两行标题、描述和图片。

滚轮、触控板、触屏和键盘滚动共享同一条连续时间线。鼠标移动驱动主体转动、图层视差、光照方向和图片倾斜。缩小画面上的荧光笔划按滚动进度描绘；进入白色段落时，椭圆遮罩逐渐展开，深色画面退远，双栏内容进入。所有转场均可随反向滚动还原。右侧章节导航和菜单可以直接定位，画廊图片及双栏入口可以打开占位预览。页面包含小屏布局、键盘焦点和减少动画偏好支持。

滚动行程为原版的三分之二。滚轮、章节跳转由同一个动画循环控制，页面位置与画面同步；触屏和键盘保持原生滚动。普通鼠标滚轮使用 1.35 倍推进，触控板保留原始增量；反向输入会立即取消上一方向的余量。隐藏场景暂停逐帧更新，转场环使用缩放替代宽高变化。

原目录中的 `index.html` 和 `styles.css` 保持原样。开发参考素材位于 `reference/`，不随网站发布。
